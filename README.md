# portfolio-devops

Сайт-портфолио на Next.js (App Router) + TypeScript + Tailwind CSS. Тёмная тема, две страницы:

- `/` — обо мне (данные из резюме)
- `/infrastructure` — интерактивная диаграмма инфраструктуры, на которой развёрнут сайт

## Разработка

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).

## Обновление контента

Все тексты вынесены из компонентов в данные — редактировать код страниц не нужно:

- `src/data/profile.ts` — резюме: контакты, опыт, навыки, образование, языки
- `src/data/infrastructure.ts` — узлы и связи диаграммы инфраструктуры

## Сборка

```bash
npm run build
npm start
```

CI/CD (GitHub Actions) и деплой на серверы настраиваются отдельно, в этом репозитории — только код сайта.
